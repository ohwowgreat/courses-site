# Media Studies · S1 CS6: Editing, Continuity Held and Broken

## At a glance

| | |
|---|---|
| Date | Mon 2026-09-28, in class |
| What | Two versions of Wednesday's three-shot sequence |
| Marked on | AO1 + AO3 |

## Objectives

By the end of this task you can:

1. Cut a sequence that holds the continuity system
2. Break the 180-degree rule deliberately and control the break
3. Name in correct terms what changes for the viewer

## Description

Two versions of the three-shot sequence you shot on Wednesday.

**Version one holds the 180-degree rule.** Establishing shot, shot / reverse shot, one eyeline match, and the geography of the room stays stable.

**Version two breaks it on purpose.** The camera crosses the line and the two people appear to swap sides mid-conversation.

Both posted, with two or three sentences naming what breaks in version two, and what the continuity system was doing for the viewer in version one.

Making the error deliberately is how you stop making it accidentally.

## Guidelines

- Use Wednesday's footage. This is an editing task, not a reshoot.
- Version one must actually hold. Check it plays without the room jumping.
- Version two must break the line specifically, not just be worse.
- Choose one transition in version two and justify it.
- Write two or three sentences, using the terms: 180-degree rule, crossing the line, eyeline match, shot / reverse shot.
- Post both, dated, same day.

## Rubric

| Band | What it looks like |
|---|---|
| **Strong** | Version one holds cleanly. Version two breaks the line unmistakably and on purpose. The writing names the break and explains what continuity was doing, in correct terms. |
| **Secure** | Both versions present and distinguishable, writing broadly correct with minor term slips. |
| **Developing** | Version one has accidental continuity errors, so the pair does not contrast, or the writing describes the feeling rather than naming the technique. |
| **Not yet** | One version only, or not posted. |

Marked on the continuity version actually holding, the break being the intended one rather than an accident, and the written difference using the right terms.
