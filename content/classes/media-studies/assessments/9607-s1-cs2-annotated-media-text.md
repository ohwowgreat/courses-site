# Media Studies · S1 CS2: Annotated Media Text

## At a glance

| | |
|---|---|
| Due | Fri 2026-09-11, set on the Monday |
| What | An everyday media text, annotated with at least six code labels |
| Cap | 30 minutes |
| Marked on | AO1 |

## Objectives

By the end of this task you can:

1. Find the four code families at work in a text you meet outside class
2. Label a code accurately rather than approximately
3. Choose a text dense enough to reward analysis

## Description

Choose an everyday media text and annotate it with **at least six accurate code labels**.

Everyday means everyday: a poster in the corridor, a drink can, an app screen, a shop sign, a bus advertisement. Not a film still handed out in class.

The labels come from the four families: **technical** (camera, light, edit), **symbolic** (objects, colour, gesture, dress), **written** (any text in frame), **audio** where it applies.

It is peer-checked against the exemplar before it is collected. Six accurate labels is the bar.

## Guidelines

- The 30-minute cap is real. Size the text so it fits.
- Choose something with several things happening. A plain white sign gives you nothing.
- Six labels minimum, and they must be accurate. Four right beats eight approximate.
- Label the code, then say in a few words what it does.
- Cover at least three of the four families. Six symbolic labels is one family, six times.
- Bring the text itself, or a clear photograph of it.

## Rubric

| Band | What it looks like |
|---|---|
| **Strong** | Six or more accurate labels across at least three families, each with a brief note on its effect. The text chosen is genuinely dense. |
| **Secure** | Six accurate labels, mostly across families, effects noted briefly. |
| **Developing** | Fewer than six accurate labels, or all of one family, or labels naming the thing rather than the code. |
| **Not yet** | Labels are wrong or absent, or the text is too plain to analyse. |
