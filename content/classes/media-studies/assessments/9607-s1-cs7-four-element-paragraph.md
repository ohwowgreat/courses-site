# Media Studies · S1 CS7: The Four-Element Paragraph

## At a glance

| | |
|---|---|
| Date | Thu 2026-10-08, in class, 15 minutes |
| When | First session back from the break, four school days before A1 |
| Marked on | AO2 |

## Objectives

By the end of this task you can:

1. Run all four technical elements across one extract in a single pass
2. Write in exam register under time
3. Move from technique to representation in one paragraph

## Description

One analytical paragraph on an unseen extract, in exam register, moving in a fixed line: **technique named, correct terminology, meaning created, link to how a person, place or event is represented.**

At least three of the four technical elements must appear.

**This is A1 with the stakes off, four school days early**, and it is the single best predictor of how A1 will go. Whatever this paragraph shows you, you have four days to act on it.

## Guidelines

- The extract plays twice. Watch the first time, take notes in protocol order the second.
- Protocol order: framing, camera, light, mise-en-scene, sound, edit.
- Fifteen minutes of writing. Plan for two.
- Three elements minimum. Coverage is what examiners notice missing.
- Every technique needs an effect. A list of named techniques scores poorly.
- End on representation. That is the move the mark scheme is looking for.

## Rubric

| Band | What it looks like |
|---|---|
| **Strong** | Three or four elements, each named with correct terminology, each tied to an effect, and the paragraph closes on a representation claim supported by what came before. |
| **Secure** | Three elements covered, terminology mostly accurate, effects stated, representation claim present but asserted. |
| **Developing** | One or two elements, or techniques listed without effects, or no representation link. |
| **Not yet** | Description of the extract with no analytical move. |

The gap between this and A1 is four days. Use what it tells you.
