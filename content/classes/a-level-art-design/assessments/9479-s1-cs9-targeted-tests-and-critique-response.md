# A Level Art & Design · S1 CS9: Targeted Tests and the Critique Response

## At a glance

| | |
|---|---|
| Due | Fri 2026-11-27, written annotation |
| What | Tests aimed only at what the critique left unresolved, plus your response |
| Rule | No test exists because it was enjoyable |
| Feeds | A3 |

## Objectives

By the end of this task you can:

1. Turn critique into a specific question you can test
2. Run a test that answers that question and no other
3. Show that feedback changed the work, not just your notes

## Description

Tests run **only on what the critique left unresolved**, each labelled with **the question it answered**. Plus the **acted-on critique response**: what the room said, and what you then did.

The rule is strict: **no test exists because it was enjoyable.** Running one more happy experiment with a medium you like is not development. Development is aiming at the thing that is not working yet.

## Guidelines

- Start from the critique notes. List what was left unresolved.
- Turn each unresolved item into a question with a testable answer.
- One test per question. Label it with the question.
- Say what the test showed, including when it showed the idea does not work.
- The response must name a change you made to the work itself.
- If a test does not trace back to the critique, leave it out of this submission.

## Rubric

| Band | What it looks like |
|---|---|
| **Strong** | Every test traces to a specific unresolved point, is labelled with its question, and the response names concrete changes made to the work. |
| **Secure** | Tests are targeted and labelled; the response describes changes though somewhat generally. |
| **Developing** | Some tests are untargeted or unlabelled, or the response records the critique without acting on it. |
| **Not yet** | Tests unrelated to the critique, or no response recorded. |
