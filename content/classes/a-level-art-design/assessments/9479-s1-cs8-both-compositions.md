# A Level Art & Design · S1 CS8: Both Compositions

## At a glance

| | |
|---|---|
| Due | Fri 2026-11-20, photographed and laid out |
| What | Compositions 1 and 2, side by side |
| Requirement | Equal effort on both |
| Feeds | A3 |

## Objectives

By the end of this task you can:

1. Develop a genuine alternative rather than a strawman
2. Document two options honestly, side by side
3. Use a comparison as evidence for a decision

## Description

**Compositions 1 and 2, side by side, documented honestly.**

Composition 2 must be **genuinely the rejected alternative at equal effort.** This is the whole point and it is where people lose marks. A finished Composition 1 next to a half-hearted Composition 2 proves nothing: of course the finished one is better. An unequal pair is not evidence, it is a foregone conclusion drawn twice.

The comparison is what the examiner reads. Make it a real one.

## Guidelines

- Two compositions, both carried to the same stage.
- Photograph both under the same light, same distance, same angle.
- Lay them out together so they can be compared in one look.
- Write what each does better. Both must have something.
- If you already know which one wins before you make the second, you have not made an alternative.
- Honest documentation includes photographing the one you like less, properly.

## Rubric

| Band | What it looks like |
|---|---|
| **Strong** | Two compositions at genuinely equal effort, documented under matched conditions, with a comparison naming a real strength in each. The decision follows from the comparison. |
| **Secure** | Both present at comparable effort, documented adequately, comparison stated. |
| **Developing** | Visible effort gap between the two, or documentation inconsistent, or the comparison only lists faults in the rejected one. |
| **Not yet** | One composition only, or the second is a sketch standing in for an alternative. |
