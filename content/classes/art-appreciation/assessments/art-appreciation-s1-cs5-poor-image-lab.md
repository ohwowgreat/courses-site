# Art Appreciation · S1 CS5: The Poor-Image Lab

## At a glance

| | |
|---|---|
| Date | Wed 2026-12-09, in class |
| What | Degrade an image on purpose, then describe exactly what changed |
| Writing | Fifteen minutes |
| Rehearses | A4 |

## Objectives

By the end of this task you can:

1. Degrade an image deliberately and control how you did it
2. Describe a change without ranking it
3. Say what a copy loses and what it gains, in specific terms

## Description

You make an image worse on purpose: compress it, re-photograph it off a screen, screenshot the screenshot, send it and save it back. Then you write for fifteen minutes on **exactly what changed, not that it got worse.**

"Worse" is a verdict. "The reds flattened, the text became unreadable, the edges grew a halo" is an observation. Only the second kind is markable.

It is the only session all term where you make something worse deliberately, and it is direct practice for A4.

## Guidelines

- Keep the original. You cannot describe a change without both states.
- Degrade it at least three times over, not once.
- Write down what you did at each step, in order, so the process is repeatable.
- Describe at least three specific changes: color, sharpness, text, edges, scale, file size.
- Do not write "quality". Name the property that changed.
- One closing sentence: what does this copy now do that the original could not?

## Rubric

| Band | What it looks like |
|---|---|
| **Strong** | The process is recorded step by step, three or more changes are named precisely, and the closing sentence identifies something the degraded version gains, such as travelling further or being easier to share. |
| **Secure** | Process recorded, two or three changes named, closing sentence present but general. |
| **Developing** | The writing reports that the image got worse without naming what changed, or names one change only. |
| **Not yet** | A verdict on the copy, or no record of what was done to it. |

The last sentence is where the unit's argument lives. A poor image is not only a loss.
